CONCEPT

* Interactive portfolio world
* Forest-themed horizontal scrolling experience
* Camera-based navigation through layered depth (not standard webpage scroll)

⸻

STRUCTURE

HTML

* 5 layers implemented:
    * .bg → background / identity layer
    * .mb → middle background
    * .mm → main content layer
    * .mf → near interaction layer
    * .fr → front / UI layer
* All layers wrapped in main.scroll
* Script loaded with defer to ensure DOM availability

⸻

CSS SYSTEM

Core styling

* Dark base color: #0E0758
* Typography system:
    * H1: Sekuya (title / identity)
    * H2: Saira Stencil One (structure / headers)
    * P: Ubuntu (body text)

Layer system

* Z-index structure: 2 / 4 / 6 / 8 / 10
* Each layer:
    * position: absolute
    * full viewport height
    * extended width (~300vw)

Layout intent

* Horizontal world instead of vertical page scroll
* Background image used as forest environment base

⸻

JAVASCRIPT SYSTEM

Core mechanics

* Wheel input via deltaY
* Camera system with two-state model:
    * target = desired scroll position
    * current = smoothed actual position

Physics

* Easing-based motion:
    current += (target - current) * 0.08

Scroll limits

* Initial fixed maxScroll replaced with dynamic value:
    scrollWidth - innerWidth

Parallax system

* Layer movement speeds:
    * bg → slowest
    * mb → slow
    * mm → medium
    * mf → fast
    * fr → fastest
* Creates depth illusion through differential translation

⸻
